Cross-Embodiment → NVIDIA Cosmos: generating new backgrounds

Taking the bimanual-YAM video feed and re-rendering its environment with a video-to-video world model — running locally on an RTX 5090.

Cosmos Transfer2.5-2B edge control RTX 5090 · WSL2 Ubuntu 480p · 93 frames ~4 min / clip

The idea

The cross-embodiment pipeline renders a YAM bimanual robot into human manipulation video. To make that data robust, we want to vary the environment — same robot motion, many backgrounds. NVIDIA Cosmos Transfer is a video-to-video "world transfer" model built for exactly this: feed it a video plus a structural control signal, and it regenerates everything else from a text prompt.

We drive it with a Canny edge map (deterministic, computed straight from the RGB frames — no flaky learned depth). The edge map pins the robot, box, crate, and HUD geometry; the prompt repaints the surrounding world.

What we learned

LeverFinding
edge control_weight0.5 > 0.7 for background replacement — lower weight commits to the new environment instead of fighting the original.
promptSimpler scenes (minimalist lab) render noticeably cleaner than busy ones at 480p.
resolution480p is the practical ceiling on a 32 GB 5090; the base model wants ~65 GB at 720p.
control modalityCanny edge — deterministic, no flicker. (Depth maps were too flaky.)
